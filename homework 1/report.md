## 題目一：Ackermann Function

## 解題說明

題目要求實作 Ackermann Function（阿克曼函數），然後分別使用「遞迴」與「非遞迴」的方法完成。

Ackermann Function 定義：

$$
A(m,n)=
\begin{cases}
n+1 & m=0\\
A(m-1,1) & m>0,\ n=0\\
A(m-1,A(m,n-1)) & m>0,\ n>0
\end{cases}
$$

---

## 解題策略

### 1.遞迴方法

遞迴版本直接依照 Ackermann Function 的定義進行處理。

先判斷目前的 `m` 和 `n`：

1. 如果 `m == 0`，直接得到 `n + 1`。
2. 如果 `m > 0` 且 `n == 0`，將問題轉換成 `A(m-1,1)`。
3. 如果 `m > 0` 且 `n > 0`，先處理 `A(m,n-1)`，再將得到的結果拿去計算 `A(m-1,結果)`。

因此第三種情況需要進行巢狀遞迴。

這種方式的優點是程式和數學公式很接近，容易理解。

---

### 2. 非遞迴方法

非遞迴版本就是不直接使用函式自己呼叫自己，而是使用陣列：

```cpp
long st[10000];
```

來記還沒有處理完成的 `m` 值。

另外使用：

```cpp
int top = -1;
```

表示目前陣列使用到的位置。

程式一開始先將輸入的 `m` 放入 `st`：

```cpp
st[++top] = m;
```

接著透過：

```cpp
while (top >= 0)
```

不斷處理陣列中的資料。

當：

```cpp
m == 0
```

代表已經到達 Ackermann Function 的基本條件，所以：

```cpp
n = n + 1;
```

當：

```cpp
n == 0
```

根據公式：

```text
A(m-1,1)
```

所以將 `m-1` 放入陣列，並把 `n` 設定成 `1`。

最麻煩的情況是：

```text
m > 0 且 n > 0
```

這時候需要處理：

```text
A(m-1,A(m,n-1))
```

程式會先將：

```cpp
m - 1
```

記起來，再處理：

```cpp
A(m,n-1)
```

用陣列保存還沒完成的工作，模擬原本遞迴的執行順序。

---

## 程式實作

### 1. 遞迴版本

程式(遞迴):

```cpp
#include<iostream>
using namespace std;
int A(int m, int n)
{
	if (m == 0) { return n + 1; }
	else if (m > 0 && n == 0) { return A(m - 1, 1); }
	else if (m > 0 && n > 0) { return A(m - 1, A(m, n - 1)); }
}
int main()
{
	int a, b;
	while (cin >> a >> b)
	{
		cout << A(a, b) << endl;
	}
	return 0;
}
```

## 程式說明

主要函式：

```cpp
int A(int m, int n)
```

其中：

- `m`：第一個參數。
- `n`：第二個參數。

當：

```cpp
if (m == 0)
```

表示已經到達遞迴的基本條件：

```text
A(0,n) = n + 1
```

因此直接：

```cpp
return n + 1;
```

如果：

```cpp
n == 0
```

則依照公式：

```text
A(m,0) = A(m-1,1)
```

所以程式：

```cpp
return A(m - 1, 1);
```

最後，如果 `m` 和 `n` 都大於 0：

```cpp
return A(m - 1, A(m, n - 1));
```

這裡會先計算內層的：

```text
A(m,n-1)
```

再將得到的結果拿去計算：

```text
A(m-1,結果)
```
---

### 2.非遞迴版本

程式(非遞迴):

```cpp
#include<iostream>
using namespace std;
int A(long m, long n)
{
	long st[10000];
	int top = -1;
	st[++top] = m;
	while (top >= 0)
	{
		m = st[top--];
		if (m == 0)
		{
			n = n + 1;
		}
		else if (n == 0)
		{
			st[++top] = m - 1 ;
			n = 1;
		}
		else
		{
			st[++top] = m - 1; //先把A(m-1,結果)記住
			st[++top] = m; //再算A(m-1,A(m,n-1))裡的A(m,n-1)
			n = n - 1;
		}
	}
	return n;
}
int main()
{
	int x, y;
	cout << "輸入(x,y):" << endl;
	cin >> x >> y;
	cout << A(x,y);
	return 0;
}
```

## 程式說明

非遞迴版本沒有直接使用函式遞迴，而是使用陣列 `st` 來保存還沒完成的 `m`。

```cpp
long st[10000];
```
這個陣列可以看成是程式自己建立的一個簡單工作區。
```cpp
int top = -1;
```
用來記錄目前陣列最後一個有效位置。

```cpp
st[++top] = m;
```
將原本的 `m` 放進陣列。
接下來：
```cpp
while (top >= 0)
```
只要陣列中還有需要處理的資料，就繼續執行。

---
### `m == 0`

```cpp
if (m == 0)
{
    n = n + 1;
}
```
這代表已經到達 Ackermann Function 的基本條件。

---
### `n == 0`
```cpp
else if (n == 0)
{
    st[++top] = m - 1;
    n = 1;
}
```

這對應：
```text
A(m,0) = A(m-1,1)
```
所以將 `m-1` 放到陣列中，並將 `n` 設成 `1`。

---
### `m > 0 且 n > 0`
### 程式：
```cpp
else
{
    st[++top] = m - 1;
    st[++top] = m;
    n = n - 1;
}
```
對應：

```text
A(m,n) = A(m-1,A(m,n-1))
```

這裡會先把：

```text
m-1
```

記起來，因為後面還要使用。

接著把：

```text
m
```

放入陣列，讓程式先處理：

```text
A(m,n-1)
```

陣列 `st` 在這裡的功能，就是保存之後還需要處理的資料。

由程式自己使用陣列來管理。

# 效能分析

Ackermann Function 的成長速度非常快，因此不適合使用太大的輸入值。

### 1. 遞迴版本

遞迴版本會一直建立新的函式呼叫，因此執行時會使用系統的 Call Stack。

當輸入值增加時，函式呼叫次數會快速增加，造成：

- 執行時間增加。
- Call Stack 使用量增加。
- 遞迴太深時可能發生堆疊溢位。

因此本題的時間複雜度不適合使用一般的 `O(n)` 或 `O(n²)` 來表示，可以描述成會隨 Ackermann Function 的輸入快速增加。

空間方面主要來自遞迴深度，因此可以表示為：

```text
O(recursion depth)
```
---
### 2. 非遞迴版本
非遞迴版本雖然沒有使用函式自己呼叫自己，但是仍然需要保存尚未完成的工作。

本程式使用：

```cpp
long st[10000];
```

來保存資料。

因此它不需要依靠系統 Call Stack，而是使用自己宣告的陣列。

不過陣列大小固定為 `10000`，如果需要保存的資料超過陣列範圍，就可能造成陣列空間不足。

因此非遞迴版本雖然可以避免直接使用函式遞迴造成的堆疊溢位，但也有自己的陣列容量限制。

# 題目二：冪集合（Power Set）

## 解題說明

題目要求輸入一個字串，利用遞迴方式找出字串中所有可能的冪集合。

例如輸入：

```text
ABC
```

每一個字元都有「選擇」和「不選擇」兩種可能。

所以可以產生：

```text
{  }
{ C }
{ B }
{ BC }
{ A }
{ AC }
{ AB }
{ ABC }
```

如果原本的集合有 `n` 個元素，每一個元素都有兩種選擇，因此總共會有：

```text
2^n
```

個子集合。

這題使用遞迴將每個字元分成兩種情況，並使用字串 `a` 記錄目前已經選擇的字元。

---

# 解題策略

這題主要使用「選擇」與「不選擇」的方式來建立所有子集合。

程式中的：

```cpp
P(s, m + 1, n);
```

代表不選擇目前的字元。

接著：

```cpp
a.push_back(s[m]);
```

將目前字元加入目前的冪集合。

再執行：

```cpp
P(s, m + 1, n);
```

代表選擇目前的字元。

當兩種情況都處理完後：

```cpp
a.pop_back();
```

將剛才加入的字元移除。

這樣就可以恢復到原本的狀態，再繼續處理其他可能。

因此整個流程可以表示成：

```text
目前字元
   │
   ├── 不選擇
   │
   └── 選擇
          │
       加入 a
          │
        遞迴
          │
       移除 a
```

這種方式也可以看成是一種簡單的回溯（Backtracking）。

---

## 程式實作

程式:

```cpp
#include <iostream>
#include <string>
using namespace std;

string a;

void P(string s, const int m, const int n)
{
    if (m == n)
    {
        cout << "{ ";

        for (int i = 0; i < a.size(); i++)
        {
            cout << a[i];
        }

        cout << " }" << endl;
    }
    else
    {
        P(s, m + 1, n);

        a.push_back(s[m]);

        P(s, m + 1, n);

        a.pop_back();
    }
}

int main()
{
    string s;

    if (cin >> s)
    {
        int t = s.size();
        P(s, 0, t);
    }

    return 0;
}
```
---

## 程式說明

### 1.全域變數 `a`

```cpp
string a;
```

`a` 用來記錄目前已經選擇的字元。

例如目前選擇：

```text
A
```

則：

```text
a = "A"
```

如果接著選擇 `B`：

```text
a = "AB"
```

因此 `a` 可以看成目前正在建立的子集合。

---

### 2.`P()` 函式

```cpp
void P(string s, const int m, const int n)
```

其中：

- `s`：原本輸入的字串。
- `m`：目前處理到的位置。
- `n`：字串的長度。

例如：

```text
ABC
```

則：

```text
n = 3
```

而 `m` 會從 `0` 開始逐漸增加。

---

### 3.遞迴終止條件

```cpp
if (m == n)
```

表示所有字元都已經處理完成。

這時目前的 `a` 就是一個完整的冪集合。

因此程式會將 `a` 裡面的內容輸出。

---

### 4.不選擇目前字元

```cpp
P(s, m + 1, n);
```

這個遞迴呼叫代表目前的字元不加入冪集合。

例如目前處理：

```text
A
```

如果不選擇 `A`，就直接繼續處理下一個字元。

---

### 5.選擇目前字元

```cpp
a.push_back(s[m]);
```

這一行會將目前的字元加入 `a`。

例如：

```text
a = ""
```

目前字元為：

```text
A
```

執行：

```cpp
a.push_back('A');
```

之後：

```text

```

接著繼續遞迴。

---

### 6.恢復原本狀態

當選擇目前字元的分支完成後：

```cpp
a.pop_back();
```

會將最後加入的字元移除。

例如：

```text
a = "AB"
```

執行：

```cpp
a.pop_back();
```

之後：

```text
a = "A"
```

這樣就可以回到上一層的狀態，繼續處理其他可能。

## 效能分析

假設輸入字串長度為 `n`。

每一個字元都有：

```text

```

兩種情況。

因此總共會產生：

```text

```

種冪集合。

如果只計算產生結果的數量，可以看成：



```text
O(n)
```

另外全域字串 `a` 最多也會儲存 `n` 個字元。

這題的額外空間主要和 `n` 有關。

## 申論及開發報告

### 1.從資料結構角度理解 Power Set

Power Set 可以看成是一個需要搜尋所有可能結果的問題。

每一個元素都只有兩種狀態：

```text
選擇
不選擇
```

所以可以使用二元的方式建立整個解題過程。

例如輸入：

```text
ABC
```

可以想成：

```text
A
├── 不選
│   └── B
│       ├── 不選
│       └── 選
│
└── 選
    └── B
        ├── 不選
        └── 選
```

之後再繼續處理 `C`。

因此整個遞迴過程其實可以看成一棵二元決策樹。

---

### 2.遞迴與決策樹

以 `ABC` 為例，每一個字元都會產生兩個分支。

第一層：

```text
A 不選
A 選
```

第二層：

```text
B 不選
B 選
```

第三層：

```text
C 不選
C 選
```

所以總共有：

```text
2 × 2 × 2 = 8
```

種結果。

這也就是：

```text
2^3 = 8
```

---

### 3.`push_back()` 與 `pop_back()` 的作用

本題使用：

```cpp
a.push_back(s[m]);
```

和：

```cpp
a.pop_back();
```

來管理目前的冪集合。

`push_back()` 的功能是將元素加入字串最後面。

例如：

```text
a = "A"
```

加入 `B`：

```text
a.push_back('B');
```

結果：

```text
a = "AB"
```

之後如果要回到上一個狀態：

```cpp
a.pop_back();
```

就會變成：

```text
a = "A"
```

因此這兩個函式可以搭配遞迴完成「加入、處理、恢復」的流程。

---

### 4.回溯的概念

這題的：

```cpp
a.push_back(s[m]);
P(s, m + 1, n);
a.pop_back();
```

可以看成一個簡單的回溯過程。

流程：

```text
加入元素
   ↓
進入下一層
   ↓
產生結果
   ↓
返回上一層
   ↓
移除元素
   ↓
嘗試其他可能
```

這種方法在資料結構與演算法中很常見，例如排列、組合等問題都可以使用類似的概念。

---

### 5.全域變數 `a` 的使用

本程式使用：

```cpp
string a;
```

作為全域變數。

這樣在遞迴函式 `P()` 中就可以直接修改目前的子集合，而不需要每一次呼叫函式都重新建立一個新的字串。

當選擇一個元素時：

```cpp
a.push_back(s[m]);
```

當返回上一層時：

```cpp
a.pop_back();
```

因此 `a` 會隨著遞迴深度改變。

## 作業總結

本次作業主要練習遞迴以及資料結構中的 Stack 與回溯概念。

第一題 Ackermann Function 分別使用遞迴與非遞迴方式實作。

遞迴版本直接利用函式自己呼叫自己的方式完成計算，可以比較直接地對應 Ackermann Function 的數學公式。

非遞迴版本則使用陣列 `st` 與 `top` 保存尚未完成的資料，將原本由系統 Call Stack 處理的部分改成由程式自己管理。

第二題 Power Set 則是利用每個元素「選擇」和「不選擇」的方式產生所冪集合。

程式利用：

```cpp
push_back()
```

加入目前選擇的元素，再利用：

```cpp
pop_back()
```

恢復原本狀態，因此可以產生所有可能的冪集合。
